# Dev Command For Windows

![Version](https://img.shields.io/badge/version-1.0.0-blue)

**Dev Command For Windows** est un outil en ligne de commande (CLI) permettant de simplifier la création, l'analyse et l'exécution de projets de développement sous Windows.

Il regroupe plusieurs commandes utiles pour les développeurs dans un seul programme.

---

## ✨ Fonctionnalités

- 🔍 Analyse de projets Python
- 📦 Installation de logiciels via Winget
- 🏗️ Création automatique de projets
- 🔄 Conversion de fichiers de projets
- 🖥️ Ouverture rapide dans Visual Studio Code
- ▶️ Exécution de projets
- 🌳 Affichage de l'arborescence
- 🔄 Système de mise à jour automatique
